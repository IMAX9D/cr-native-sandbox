# 第三轮优化：全部候选已实现并测试，按结果选择

日期：2026-09-12。F78：25 核 CPU 配额、92 GiB 内存、RTX 5090 D 32 GB。
模型：restart319051，4,804,205 参数；游戏与模型合同沿用冻结的 x86_64 150535029。

## 结论

五项优先级均已进行实现或接线、对照验证。**不等于把所有候选默认启用，也不等于完成全网络、动态联赛、无人值守正式训练。**

本轮推荐 **向量化/受控减少复制 + 第二轮在线路径 + 有界 CUDA Graph**。12×4 匹配对照从 **6,227.8 → 7,028.7 聚合 tick/s，提升 12.86%**，显存从 8,446 增至 11,020 MiB。CPU 平均占用约 12 核，未发生 OOM。

固定缓冲区单独使用没有稳定收益；当前编译方案及 JSON→MessagePack 转换方案更慢，不选为默认。紧凑训练观测减少约 58% 的采样 JSON 字节，但没有带来本机吞吐增益，作为显式可选接口保留。

真实的异步采集—学习小闭环已通过：**1,024 个学习方决策样本、8 次策略头/价值头更新**。主干、LSTM、对手与原始权重文件保持不变，测试快照单独保存。

## 2. 多并发推理结果

同一批 48 个种子，每组 12 个进程×4 局；执行 control/buffers/graph/graph/buffers/control。每次 48 场、279,523 tick、8,251 次出牌，逐局动作摘要和终局均相同。

| 方案 | 每次平均耗时 | 聚合 tick/s | 峰值显存 |
|---|---:|---:|---:|
| 第二轮 dense 对照 | 44.883 s | **6,227.8** | 8,446 MiB |
| 向量化/少复制＋固定缓冲区 | 44.969 s | 6,215.8 | 11,144 MiB |
| 向量化/少复制＋CUDA Graph | 39.769 s | **7,028.7** | 11,020 MiB |

Graph 组合吞吐提升 12.86%，单组耗时降低约 11.4%；增加约 2.51 GiB 显存。它以显存和实现复杂度换取更少的 GPU 调度开销，不是免费收益。

不能把本轮百分比直接乘以前轮百分比，也不能用本轮 48 场与前轮 96 场混算严格收益。16/24 进程的新配置未在本轮重新寻找全局最优点。

### Graph 的正确性与限制

- 缓存上限 8 个形状，实体轴按不小于真实数量的桶补零，不截断实体；超容量显式回退。
- 限定在线单时间点、有效帧；训练序列、reset 等一般路径使用原参考实现。
- 保留历史维度、有限数、非负时间、输入合同及输出检查。
- 隐藏状态必须独立持有。第一版复用了 Graph 输出存储，被验证器抓到不同玩家的状态混用；已修复并保留失败证据。
- 修复后通过 1,000 次 scalar/batched 动作验证、2,125 次 Graph 重放对照及完整对局/多并发匹配。
- 这是每个采集进程独立使用 Graph，不是一个中央推理服务同时支持任意并发调用。

## 3. 观测向量化与减少复制

网格聚合使用有序 `np.add.at`，避免改变同格多个实体累加顺序；量化、边界与词表检查保持不变。513 个合成网格覆盖 0～512 实体及拥挤同格情况，结果精确一致；微测约 0.375→0.255 秒，不将此数字外推为整机收益。

实体字段以数组批量填入。状态补充只复制会修改的顶层、玩家和实体节点，嵌套诊断结构共享只读引用。这依赖受控采集器的所有权规则，**不能直接替换对外承诺深拷贝语义的通用 API**。

单进程向量化单项测试没有显著稳定增益；Graph 组合的多并发结果才是本轮主要采用依据。

## 4. 传输接口的结果

### 完整 JSON 转二进制：实现了，但不选用

实现了 `CRB1 + 大端长度 + MessagePack` 响应协议，使用紧凑整数/字符串编码，限制帧大小及嵌套深度。请求保留 JSON-line，响应显式选择 `response_wire=msgpack-v1`。新增依赖为 `msgpack 1.2.2`。

验证包含完整同帧字段相等、6,152 次黄金观测对照、604 次已接受动作、30 次活跃槽位 reset，以及分片接收、错误 magic、超长帧、截断和错误响应等 5 项协议测试。状态变更请求只发送一次，不自动重试。

| 单进程四局 | 平均耗时 |
|---|---:|
| 完整 JSON | 28.473 s |
| 完整 JSON→MessagePack | 44.413 s |

转换版约慢 56%。当前实现仍先由原生生成 JSON，再由 Java 解析并转换；额外对象构造抵消了传输优势。它不是“原生直接输出列式二进制”，不应换个编码名称就宣称优化成功。直接原生列式写出仍是后续可研究项，本轮不把它记作已完成。

### 原生紧凑训练观测：数据更少，但本机并未更快

将已有 `nativeObserveTrain` 接到四局批量接口，显式 `observation_schema=train-v1`；新宿主提供能力探测，客户端在操作前确认支持，收到不匹配 schema 时拒绝继续。完整调试观测默认保留。

紧凑模式不生成模型不使用的诊断字段、路径细节等，但不减少战斗运算。验证了同一未推进的对局中 **800 帧、1,600 个玩家视角**，规范化状态、全部模型张量、技能键与 mask 一致。

采样 JSON 字节：8,059,397→3,391,731，减少 **57.92%**。这是这组观测序列化字节，不是总磁盘/所有数据量减少 58%。

12×4，graph/graph-compact/graph-compact/graph 匹配对照：

| 方案 | 平均耗时 | 聚合 tick/s |
|---|---:|---:|
| Graph＋完整观测 | 39.634 s | **7,052.7** |
| Graph＋紧凑训练观测 | 39.922 s | **7,001.7** |

差约 -0.72%，没有证明吞吐改善。它可作为减少数据量的选项，不作为本机提速默认。紧凑观测再转 MessagePack 的单进程测试也没有收益。

## 5. 编译方案

使用动态形状、`reduce-overhead` 的 Torch 编译候选，并保留在线单步与历史检查。第一次数值验证失败来自测试封装的 Python 闭包变量重名，已修复；不将这个封装错误归责于编译器。

修复后通过 1,000 次动作验证以及完整四局 A/B/B/A；但本次测量包含冷启动和新形状编译成本：

| 方案 | 四局平均耗时 | 聚合 tick/s |
|---|---:|---:|
| 未编译对照 | 27.541 s | 887.5 |
| 编译候选 | 55.297 s | 442.0 |

不采用该配置作为默认。不据此断言极长驻留、其他形状约束或其他编译配置永远没有收益。

## 6. 真实采集—学习闭环

### 实现

采用两个独立进程：采集器持有行为快照，学习器持有可训练副本。队列容量 2，每段 32 个决策×4 个学习方，不再等全部完整对局结束才交数据。

只更新策略输出头与新价值头，共 **588,582 个参数**；编码主干、LSTM、上下文和对手冻结。段边界发布输出头/价值头，携带的 LSTM 记忆因此仍兼容。若以后解冻主干，这个条件不再成立，必须另行设计状态重建/发布边界。

行为为 Bernoulli 时机＋合法性约束下的类型/卡牌/位置或技能联合随机采样，不是拿贪心动作冒充 on-policy 样本。采样与训练重算共用联合 log-prob。保存真实 h0、old logp/value、合法 mask、行为版本、终局及非终局 bootstrap。

PPO 使用联合 ratio、0.2 clip、学习率 1e-5、梯度裁剪 1、更新后 KL 上限 0.02。gamma=0.999/四 tick，GAE lambda=0.95。测试奖励为终局 ±1 加公开塔血势函数差；这是隔离小闭环的明确配置，不是正式训练奖励已验收。

### 确认不是开局空场

单纯实体列表非空可能只看到固定塔，不能作为充分证据。因此另外统计了：

- **862** 个观察帧包含初始固定实体之外的新实体；
- **697** 个观察帧检测到实体移动；
- 最多同时出现 **12** 个新实体；
- 模型实际输入网格具有 **607** 个不同状态。

真实奖励在多段中非零；并非只用固定开局张量完成一次空优化器调用。

源专家文件 SHA 不变，主干和对手张量 hash 不变，学习方输出头确实变化。每次更新的局部头、价值头和优化器都已保存；八个快照均通过有限数与源模型恢复检查。

最新 `update-008.pt` 为 7,097,153 字节，SHA-256：
`b7f928c0e24e715b2ad7267098084e4f0089c47df48e7de5f7cdcc6c4bf4bb07`。

这是**局部微调测试快照，不是完整模型发布包**，不能直接覆盖人机盒子的专家文件。它没有通过胜率/Elo验收，不宣称模型变强。该短测没有完成完整比赛，1,024 是决策样本数而不是对局数。

## 7. 验证规模与最终选择

主要性能对照共 **560 次完整对局运行**，包含重复种子，不是 560 个独立样本；另外有黄金轨迹、短数值对照和两次学习小闭环。各性能组内对应对局的动作摘要与终局一致。

推荐：保留第二轮宿主/在线优化，使用本轮通过对照的 Graph 组合，12×4 作为已测试配置。保持有界图缓存与原路径回退，不把编译、二进制转换、紧凑观测全部叠加成默认。

`graph-compact` 等候选源码保留供后续研究，但“代码存在”与“正式训练已启用”严格区分。
