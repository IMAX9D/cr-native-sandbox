# 第三轮：剩余优化项的实现与对照

本目录包含实验实现，不替换默认宿主、原始专家权重或本地人机盒子。所有结果以最终报告为准，不能因某个模块实现了就默认它更快。

## 模块

| 文件 | 功能与边界 |
|---|---|
| `vector_encoder.py` | 训练网格有序向量聚合、实体数组批量填充；保留量化和词表检查 |
| `owned_enrich.py` | 只复制补充字段会修改的节点；嵌套诊断数据必须只读，仅用于受控采集器 |
| `cuda_graph.py` | 最多 8 个形状桶的 GPU 缓冲区/CUDA Graph；单步、全有效帧；隐藏状态独立持有 |
| `run_variant.py` | 原版、向量化、固定缓冲区、Graph、编译、完整/紧凑/二进制传输的显式开关 |
| `harness/.../BinaryWire.java` | MessagePack 响应协议，限制帧大小和嵌套深度；完整 JSON 转换版有额外开销 |
| `binary_client.py` | 分帧、边界和错误检查；不自动重试可能已经执行的动作 |
| `harness/.../JniHost.java` | 将原有原生紧凑训练观测接到四局接口，带能力探测；默认完整调试观测仍保留 |
| `learner_canary.py` | 独立采集进程＋学习进程，容量 2 的队列；固定主干/LSTM，只微调策略头和价值头 |
| `verify_checkpoint.py` | 用准确的专家源模型恢复隔离测试头，验证主干及原始文件未变 |

## 运行依赖

沿用已验证的 Linux Bionic 用户态、游戏资源和发布模型配套工程。该快照中的路径仍指向实测部署：

- `/root/autodl-tmp/resident-linux-20260912`：原基线脚本、模型及合同。
- `/root/autodl-tmp/resident-opt-20260912`：第二轮宿主/在线适配。
- `/root/autodl-tmp/bc-cloud-bench-20260911/core`：模型定义、卡牌/观测词表及原接口。

这里不是独立运行包。不要把旧 ARM64 偏移或其他游戏版本接进来。权重、`libg.so`、APK、Runtime 和大型运行产物不入 Git。

二进制实验新增依赖 `msgpack==1.2.2`；Torch 沿用云端已安装版本，不通过本目录升级。

## 开关与测试

- `CR_FULL_VARIANT=control`：第二轮已验证的 dense 基线。
- `vector`：向量化与减少复制。
- `buffers`：固定 GPU 输入/隐状态缓冲区。
- `graph`：有界 CUDA Graph。
- `compile`：独立 Torch 编译候选，不能绕过单步/历史/有限数检查。
- `binary`：完整观测转 MessagePack，必须搭配新 Java 宿主。
- `compact`：显式请求原生 `train-v1` 紧凑观测，只省略模型不用的诊断字段。
- `compact-binary`：紧凑观测再转 MessagePack。
- `graph-compact`：Graph 与原生紧凑观测组合。

`CR_FULL_VERIFY=1` 和 `--verify` 为正确性对照，包含额外参考计算，不能用于测速。测试驱动的启动/冷缓存开销有明确记录。

端口：第二轮宿主 25431 起；新增协议宿主 26431 起。两组都在实测机临时端口范围之外。

## 学习闭环不是正式训练

小闭环使用真实原生对局观测、按联合概率随机采样的动作、真实合法性检查与回执。对手固定，未接联赛/Elo。采集与学习是两个进程，队列容量 2，超过一版的行为数据丢弃。

仅训练策略输出头与新价值头，共 588,582 参数。主干、LSTM 和对手冻结；因此在段边界更新输出头，不改变已经携带的 LSTM 状态的编码方式。没有把这条限制偷换成全网络热更新。

PPO：32 步×4 个学习方、联合 ratio、0.2 clip、学习率 1e-5、梯度范数上限 1、KL 守卫 0.02。GAE 使用每 4 tick 的 gamma 0.999、lambda 0.95。测试奖励为终局 ±1 加公开塔血势函数差，不是已经验收的正式奖励配方。

保存实际 h0、行为版本、old logp/value、动作合法 mask、终局与截断 bootstrap。动作采样和重算共用 `joint_logp`，第一版重算必须对齐；失败更新回滚，不发布。

`update-*.pt` 是**局部头/价值头/优化器测试快照**，不是可直接替换对局盒子的完整专家模型。测试通过不证明胜率提升，也不代表全网络自博弈、动态对手池或无人值守生产训练已经完成。

## 失败试验保留

保留第一次 Graph 隐藏状态别名错误、第一次编译验证的 Python 闭包命名冲突及修复后的复测。性能不达标的二进制转换路径不自动启用。统计时区分工具/封装错误、算法差异和真实性能结果。
