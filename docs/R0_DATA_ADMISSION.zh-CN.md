## 当前固定标准

- 当前 `training_r0` 源码合同：20Hz 原生 Tick，5 Tick 决策窗口，最多两个带时间偏移的微动作。
- 保留完整命名特征库（72 子实体字段、21 塔字段等）及6项因果伤害统计，不用匿名补零凑维度。
- 正式模型 `allow_incomplete_capture=False`。未知/不适用依据具体字段的适用性与证据处理，不要求所有单位拥有所有机制，也不能把所有未知都解释为机制不存在。
- `data_pipeline/r0_admission.py` 从当前 R0 源码、配置、数据字典和观测 schema 计算合同 SHA；检查编译 manifest、各能力证书、分片与证据文件 hash，以及严格模型 batch 检查。它不声称已有通过验收的完整训练缓存，也不是一个自动生成合格证书的入口。

## 本次实修

1. 采集默认进行有上限的原生 seed 搜索与初手相容性核对。回放规划器已有 `compatible_cycle`，现在真正接入采集前置步骤；下载器有牌组/时间/动作筛选，不能把本次固定 seed 未校准造成的失败归咎为无法倒推手牌。
2. Java 宿主增加可选 Tick 0 reset 路径。默认历史 reset 仍热身到 Tick 10，避免破坏旧使用方；新采集默认要求 Tick 0 能力并检查实际首帧为0。
3. 初手校准结束后，采集开始再次核对实际手牌，防止校准后重置又换了布局。校准失败不回退到任意固定 seed。
4. 原生细节增加有界、owner 校验的攻击/移动/生命/效果组件原始整数快照。原始数据未转 FP16；尚未证实的偏移语义不强行命名为阶段。
5. 适配器修复：同 Tick 重复观测的速度基准、弹丸/效果上一帧查找、过期目标指针映射、累计异常计数反复标缺口、法术/技能公开历史遗漏、区域效果 AEO 原型映射。
6. Buff 类型从固定资源属性识别部分已知效果，弹丸追踪/半径允许使用同版本名义定义。没有把未缩放的基础伤害冒充真实等级/增益后的伤害。
7. 未归属的旧伤害不再永久使后来出生的单位全部统计失效；仍保留同一单位生涯范围内的不确定性。
