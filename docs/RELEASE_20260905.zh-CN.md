## 已验证结果

RTX 5090 D 云端连续两次更新 `policy 19→20→21`：384 场、102,326 个有效决策，
总计 506.10 秒，两次 Guard 首次通过，均保存 FP32 master/Optimizer/RNG 与 FP16 Actor。
完整短测折算约 6.56 万场/天；20 万场/天和 24 小时稳定性尚未验收。
历史 23.2 万场/天是纯采集折算，不是完整训练成绩。

本次本地 CPU 回归（Windows，Python 训练环境，PyTorch 2.11.0+cu128）：

```powershell
$env:CUDA_VISIBLE_DEVICES = '-1'
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
python -m pytest -q
```

结果：453 passed、6 skipped、54 subtests passed（57.89 秒）。
