# 2026-09-03 本地最新内核发布整理

## 发布内容

本次发布以本地 `CR-Native-Core` 为准，覆盖 GitHub 上旧的冻结沙盒源码，并保留
对外部署所需的许可证、Python 包配置、环境模板、Runtime 冻结、bootstrap、
doctor 和 smoke 入口。

纳入的主要开发内容包括：

- 最新 JNI 宿主与原生桥接；
- Binderless Android Context/PackageManager 兼容层；
- 可复位、可并发的无 Surface Worker；
- MuMu ARM64 只读采样与触控控制实验；
- Expert Training、Expert Self-Play v1、在线采样、Critic/PPO 与恢复流程；
- 新增卡组示例、实验报告和对应测试。

训练产物、模型、APK、SO、JAR、日志和本机配置继续排除在 Git 之外。

## 游戏更新后的状态

本次发布不声称已经适配商店中的最新游戏版本。

- 无界面 x86_64 内核仍严格绑定 `15.535.29 / 150535029`；
- MuMu ARM64 实验代码严格绑定 `versionCode 160402002`；
- 任何更新后的未知 build 都必须重新定位并重新认证；
- 版本不匹配时应 fail closed，不允许只改版本号或绕过守卫。

## 对外运行入口

新用户应从仓库根目录按顺序执行：

```powershell
Copy-Item runtime.env.example.ps1 runtime.env.ps1
. .\runtime.env.ps1
.\scripts\bootstrap.ps1
.\scripts\doctor.ps1
.\scripts\smoke.ps1
```

其中 Runtime/APK 必须由用户合法提供。仅阅读代码或运行纯 Python 单元测试时，
不需要启动 AVD。
